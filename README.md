# dsh-ide

给 DeepSeek Harness 用的 IDE 工作台插件：在会话里直接浏览项目、编辑文件、看差异、管 Git、开终端、跑项目。

不依赖任何第三方 DSH 插件，全部能力由本插件自己实现。

## 现在能做什么

当前处于 **P0 基础设施**阶段，工作台骨架已经可用：

- 会话顶部的「对话 / 轨迹」之后多出一枚 **IDE** 页签，点开就是工作台；
- 右侧栏的添加菜单里也能打开同一个工作台，并可用宿主的浮出操作变成浮窗；
- 工作台内已有四区骨架：左侧工具条、编辑区、底部面板、状态栏；
- 面板宽度与底部高度可拖拽调整，按会话记住，刷新页面后恢复。

还没有接入具体功能 —— 项目树、编辑器、差异对比、Git、终端、运行配置会在后续阶段逐个交付。

## 挂载到本地宿主

```sh
# 在插件目录构建
npm install
npm run build

# 加入 profile 的 bundles 后重启宿主
```

`package.json` 的 `dsh.bundle.patch` 指向 `cordis.patch.yml`，安装时会自动插入插件行。

开发时可用 `npm run dev` 进入监听模式，源码变化后自动重建，客户端产物由宿主热重载接管；宿主侧改动仍需重启。
