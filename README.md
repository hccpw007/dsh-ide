# dsh-ide

给 DeepSeek Harness 用的 IDE 工作台插件：在会话里直接浏览项目、编辑文件、看差异、管 Git、开终端、跑项目。

界面与右键菜单固定使用英文，不随宿主语言切换。不依赖任何第三方 DSH 插件，全部能力由本插件自己实现。

## 现在能做什么

在会话顶部「对话 / 轨迹」之后多出一枚 **IDE** 页签，点开就是工作台；右侧栏也能作为另一个入口，并可用宿主的浮出操作变成浮窗。

**浏览与编辑**

- 项目树：目录懒加载、目录优先自然排序、隐藏文件开关、按扩展名着色、键盘上下与左右导航、Git 状态着色；
- 右键菜单：@ 到对话（把文件或目录作为引用插入当前对话的输入框）、新建文件 / 目录、重命名、删除（物理删除，确认后不可恢复）、复制路径、在文件中查找、显示差异、暂存、从磁盘重新加载；
- 编辑器：CodeMirror 6 + 按扩展名加载语法高亮，多标签、拖拽排序、中键关闭、未保存确认；
- 保存：`Cmd/Ctrl+S`，带版本乐观锁——文件被外部改动时弹出「重新加载 / 覆盖」二选一，绝不静默覆盖；
- 自动保存：设置里开启后，停止输入 2 秒自动落盘。

**差异**

- 三种来源：工作区 vs HEAD（含暂存区）、两个提交之间、任意两个文件；
- 并排 / 行内两种布局，逐行红绿底与双侧行号，hunk 折叠与展开，忽略空白与大小写；
- 二进制与超过 2 MiB 的文件给出明确说明而不是乱码。

**版本控制（下方面板，三个页签）**

- 界面照 IDEA 的 Git 工具窗口重做，Git 文案与所有右键菜单固定为英文；
- 本地变更：Changes / Unversioned Files / Merge Conflicts 分组，可按目录折叠成树或平铺，并按名称 / 路径 / 状态排序；文件与分组右键可查看差异、在编辑器中打开、暂存 / 取消暂存、撤销改动、复制路径；左侧图标条可刷新、回滚、在编辑器打开差异、搁置、切换分组与排序、全部展开 / 收起；右侧内嵌并排差异，带双侧行号、词级高亮、未改动区折叠、上一处 / 下一处与文件导航、差异数量，可切并排 / 单栏；
- 日志：左侧分支树（HEAD / Local / Remote / Tags，当前分支用黄色标签、收藏用黄色星标），中间提交列表支持文本 / 正则 / 大小写 / 分支 / 用户 / 日期 / 路径过滤与排序，右侧是提交文件树与提交详情：文件行单击选中、双击打开差异，工具栏可对选中文件在编辑器中打开、查看该提交中的差异、回滚到提交之前的状态、查看该文件历史，并可切换增删统计、全部展开 / 折叠文件树；分支右键按 IDEA 分三套：当前分支可新建、与工作区比较、新建工作树、更新、推送、跟踪分支、重命名，其他本地分支另有检出并变基 / 更新、变基到该分支、合入当前分支、删除，远程分支另有比较、两种 Pull into 与删除；提交右键可签出、新建分支、cherry-pick、revert、reset、复制；
- 控制台：面板、主工具栏、项目树与弹窗执行过的 Git 写命令连同真实输出都会记进来，带时间与工作目录，stdout / stderr 分色显示，URL 可点击；左侧图标条可切换是否换行、跳到输出末尾、清空，右键可复制全部或清空；
- 冲突解决：更新工程或推送被拒后的自动合并产生冲突时弹出 Conflicts 窗口，按文件列出双方状态并可整份接受某一侧、一键解决简单冲突；点 Resolve Manually 在编辑区打开三栏合并窗口，逐块接受左右两侧、一键应用全部冲突块，中间结果栏可直接编辑，保存后写回并标记已解决，全部解决后可完成合并（推送流程会接着把提交推上去）。

**终端与运行**

- 终端：xterm，多页签、重命名、关闭、刷新后重连，折叠面板不结束进程；
- 启动器：运行配置 CRUD、一键启动、实时输出、停止（SIGTERM → 宽限期 → SIGKILL），配置持久化在 `$DSH_HOME/dsh-ide/run-configs.json`。

**定位与分析**

- 搜索：内容搜索，正则 / 大小写 / 全词 / 排除 glob，结果按文件聚合并跳转行号；

**其他**

- 对话输入行：权限选择右侧显示当前工作目录的 Git 分支（与 IDE 顶部菜单同一套图标与同步状态箭头），点击弹出分支切换列表，顶部的 Update Project / Commit / Push / New Branch / Checkout Tag 可直接打开对应对话框就地执行（提交与推送里的「查看差异 / 打开文件」仍需 IDE）；未绑定工作目录或不是 Git 仓库时不显示；
- 欢迎页：最近打开的文件；
- IDE 设置：字号、缩进、自动保存、差异上下文、搜索排除、终端 shell；
- 状态栏：分支、变更数、当前文件、运行中实例。

## 挂载到本地宿主

```sh
# 在插件目录构建
npm install
npm run build

# 加入 profile 的 bundles 后重启宿主
```

`package.json` 的 `dsh.bundle.patch` 指向 `cordis.patch.yml`，安装时会自动插入插件行。

开发时可用 `npm run dev` 进入监听模式，源码变化后自动重建，客户端产物由宿主热重载接管；宿主侧改动仍需重启。

## 数据放在哪

| 数据 | 位置 |
|---|---|
| 全局设置 | `$DSH_HOME/dsh-ide/settings.json` |
| 运行配置 | `$DSH_HOME/dsh-ide/run-configs.json` |
| 布局、标签、终端绑定 | 浏览器 localStorage，按会话隔离 |

插件只在这两处落盘；删除文件是物理删除，不写任何回收站副本。
