## 二、P0 基础设施

### 目标

让一个空壳工作台能在 DSH 里被打开，且所有后续 feature 有稳定的落位方式。

### 范围

| 项 | 内容 |
|---|---|
| 仓库脚手架 | `package.json`（`dsh.client.platform: web`、`dsh.bundle.patch`）、`tsconfig.json`（strict）、`build.ts`、`tailwind.config.ts`、`cordis.patch.yml`、`locale/{zh,en}.json`、`icon.svg`、`.gitignore`、`README.md`、`AGENT.md` |
| 双半入口 | `src/host/index.ts`（聚合 feature host、注册路由）、`src/client/index.tsx`（注册插槽与 tab 类型） |
| feature 契约 | `src/client/shell/contract.ts`、`registry.ts`（五槽位校验、排序、分组） |
| 工作台外壳 | `Workbench.tsx`、`ToolWindowBar.tsx`、`EditorArea.tsx`、`BottomPanel.tsx`、`StatusBar.tsx`，全部为占位实现 |
| 三形态注册 | A：`conversation.view` 主区标签；B：`sidebar.right.pane.tab` + `sidebarRightTabs.register(kind: 'ide')`；C：宿主原生 `sidebarRight.float()` 由用户触发，插件只保证 B 注册正确即可浮出 |
| 路由基座 | `/dsh-ide/api/ping`、统一信封、回环校验、错误码枚举 |
| 服务总线 | `shell/services/` 的空接口与注入 |
| i18n | `locale.register` + `bind` 接线，feature 语言包合并 |

### 交付物

- 可构建、可安装、可在宿主里打开的工作台空壳。
- 一条能返回 `pong` 的路由，用于验证宿主侧接线。

### 验收标准

1. `npm run build` 通过（含 `tsc --noEmit`），产出根目录 `index.js`、`client.js`。
2. **形态 A**：把插件加入 profile 后重启宿主，会话顶部标签栏在「对话」「轨迹」之后出现 **「IDE」** 标签；点击后整块主对话区渲染工作台，点「对话」可切回聊天。
3. 工作台显示四区：左工具条、编辑区占位、底部面板占位、状态栏。
4. 拖拽分隔条能改变面板尺寸，刷新页面后尺寸恢复。
5. **形态 B**：打开右侧栏 → 添加控件 → 能选择 **「IDE」** 页签并渲染同一个工作台；容器变窄时左工具条收起、底部面板变抽屉。
6. **形态 C**：在形态 B 的 IDE 页签上使用宿主的浮出操作，能把它变成可拖拽浮窗，浮窗内工作台继续可用。
7. 切到「对话」再切回「IDE」，已打开的文件与布局保持不变（D6：视图切换不销毁状态）。
8. `curl http://127.0.0.1:<port>/dsh-ide/api/ping` 返回 `{"ok":true,"value":"pong"}`。
9. 带外部 `Origin` 的请求返回 403。
10. 从 profile 移除插件并重启，宿主界面无残留、无报错。

## 三、P1 浏览

### 目标

能看见项目结构并打开文件内容（只读）。

### 范围

| feature | 交付内容 |
|---|---|
| F20 文件监听 | `ctx.fs.watch` 封装、200ms 事件合并、订阅与回收 |
| F02 项目树 | 懒加载展开、排序、dotfiles 开关、扩展名图标、右键菜单骨架（仅「打开」可用） |
| F03 只读打开 | `editorTab` 注册、文本分页读取、大文件降级、标签页管理（不含编辑） |
| 宿主路由 | `GET /dsh-ide/api/fs/list`、`GET /dsh-ide/api/fs/stat` |

### 验收标准

1. 工作台打开后，项目树显示会话 `cwd` 的直接子项，目录在前、按自然序排序。
2. 逐层展开目录时按需请求，未展开的目录不发请求（可用网络面板确认）。
3. dotfiles 默认隐藏，开关打开后显示。
4. 点击文本文件在编辑区打开标签页，内容与磁盘一致，行号正确。
5. 打开超过 2 MiB 的文件显示「文件过大，仅预览」并只加载首屏。
6. 在终端里 `touch` 一个新文件，3 秒内项目树对应目录自动出现该文件。
7. 打开已打开过的文件不新建标签页，而是聚焦已有标签。
8. 关闭工作台（或切换会话）后，所有目录监听被释放（宿主侧无残留 watcher）。

## 四、P2 编辑

### 目标

文件可编辑并安全保存。

### 范围

| 项 | 内容 |
|---|---|
| 编辑器内核 | CodeMirror 6 集成（懒加载 chunk）、行号、当前行、括号匹配、自动缩进 |
| 语言支持 | TS/JS、JSON、CSS、Markdown、Python、Go、Rust 的语法高亮（按扩展名动态加载） |
| 查找替换 | `Cmd/Ctrl+F` / `Cmd/Ctrl+H` |
| 保存 | `Cmd/Ctrl+S`、自动保存开关、脏标记 |
| 冲突检测 | 保存前版本比对，`STALE_FILE` 时弹三选一（覆盖 / 重新加载 / 另存为） |
| 宿主路由 | `POST /dsh-ide/api/fs/write`（原子写 + 版本防护）、`POST /dsh-ide/api/fs/create` |
| 标签页 | 拖拽排序、中键关闭、未保存关闭确认 |

### 验收标准

1. 修改文件后标签页显示脏标记，`Cmd/Ctrl+S` 后标记消失、磁盘内容更新。
2. 关闭有未保存改动的标签页时弹出确认，选择取消则不关闭。
3. 保存时若文件已被外部修改，弹出冲突对话框；选「重新加载」后编辑器内容替换为磁盘内容。
4. 自动保存开启时，停止输入 2 秒后自动落盘。
5. 打开 `.ts` 文件有语法高亮，打开 `.txt` 无高亮但不报错。
6. 主 bundle 体积未包含 CodeMirror（检查构建产物体积与 chunk 拆分的产物清单）。
7. 新建文件后项目树与编辑器同步显示。

## 五、P3 差异

### 目标

能看清「改了什么」。

### 范围

| 项 | 内容 |
|---|---|
| 差异引擎 | jsdiff 逐行对比，hunk 生成（上下文 3 行，可配） |
| 渲染器 | 并排 / 行内两模式、红绿底、旧新双列行号、hunk 折叠 |
| 差异源 1 | 工作区文件 vs `HEAD`（经宿主 git 服务） |
| 差异源 2 | 任意两提交之间的文件差异 |
| 差异源 3 | 任意两文件的直接对比 |
| 选项 | 忽略空白、忽略大小写 |
| 边界处理 | 二进制、超 2 MiB、删除文件、新增文件四种情况的占位展示 |

### 验收标准

1. 修改一个已跟踪文件后，从项目树右键「显示差异」能看到红绿逐行差异，行号正确。
2. 切换并排/行内模式，内容不变、布局切换。
3. 勾选「忽略空白」后，纯缩进改动不再显示为差异。
4. 对比两个提交的同一文件，差异内容与 `git diff <a> <b> -- <file>` 输出一致。
5. 二进制文件显示「无法显示差异（二进制文件）」而非乱码。
6. 2 MiB 以上文件显示大小并拒绝渲染，不卡死界面。

## 六、P4 终端

### 目标

在工作台内执行命令。

### 范围

| 项 | 内容 |
|---|---|
| 终端集成 | xterm + FitAddon（懒加载 chunk），主题跟随宿主令牌 |
| 会话 | `remote.terminal` 全接口接线：`environment`、`shells`、`create`、`attach`、`retain`、`rename`、`close` |
| 页签 | 新建、重命名、关闭、多实例 |
| 重连 | 刷新页面后按保存的绑定恢复 |
| 布局 | 底部面板高度拖拽、面板折叠不结束进程 |

### 验收标准

1. 打开终端后可在会话工作目录执行 `pwd`，输出为该会话 `cwd`。
2. shell 选择菜单列出本机可用 shell，切换后新终端使用所选 shell。
3. 同时开 3 个终端各自独立，输入不串屏。
4. 折叠底部面板后进程继续运行；重新展开输出衔接无丢失。
5. 刷新浏览器后终端自动重连，屏幕内容恢复。
6. 关闭终端页签后进程结束（可用 `ps` 确认）。
7. 创建第 9 个终端时给出上限提示而非静默失败。

## 七、P5 Git

### 目标

日常版本控制闭环。

### 范围

| feature | 交付内容 |
|---|---|
| 宿主 git 服务 | 方法表白名单、`spawn(git, argv)`、串行队列、输出上限与超时、错误码映射 |
| F06 状态 | `status` 解析、四分组、行内暂存/取消/丢弃、分组批量操作 |
| F07 操作 | checkout、branch、merge、rebase、cherry-pick、reset、tag、stash、fetch、pull、push，含确认与撤回 |
| F08 历史 | log 分页、泳道图谱、引用徽章、详情与逐文件差异 |
| F09 分支 | 分组树、ahead/behind、右键全部操作 |
| 联动 | 变更状态映射到项目树着色与状态栏计数 |

### 验收标准

1. 变更列表正确分四组，与 `git status --porcelain` 一致。
2. 暂存 / 取消暂存 / 丢弃操作后，`git status` 结果同步变化。
3. 撰写提交信息后提交成功，提交列表出现该条，变更列表清空。
4. 历史列表显示泳道连线与引用徽章，滚动加载下一页不重复。
5. 点击提交看到详情与逐文件差异，与 `git show` 一致。
6. 分支树显示本地/远程/标签分组与 ahead/behind 角标。
7. 删除 `main` 分支需输入分支名确认；取消则分支仍在。
8. 存在未结束的 merge 时，rebase 与 cherry-pick 按钮置灰并显示原因。
9. 硬重置与 force push 有二次确认，取消后仓库状态不变。
10. 所有 git 调用在宿主侧串行执行（并发触发两次写操作，第二次排队而非交叉）。

## 八、P6 运行配置

### 目标

一键启动项目并观察日志。

### 范围

| 项 | 内容 |
|---|---|
| 宿主 run 服务 | 进程登记表、`ctx.subprocess.spawn`、环形输出缓冲（按字节上限）、终止阶梯、退出码 |
| F10 运行配置 | 配置列表 CRUD、启动/停止、输出面板、历史与退出码、并行多实例 |
| 路由 | `run/start`、`run/stop`、`run/output`、`run/list` |
| 配置存储 | `$DSH_HOME/dsh-ide/run-configs.json`，按工作目录分组 |

### 验收标准

1. 新建运行配置（命令 `node -e "setInterval(()=>console.log(Date.now()),1000)"`），点启动后输出面板每秒出现一行。
2. 点停止后进程结束，输出面板显示退出码。
3. 同一配置重复启动时提示「已在运行」，不产生第二个进程。
4. 两个不同配置可并行运行，输出各自独立。
5. 关闭工作台不影响已启动进程；重新打开工作台能看到仍在运行的进程与最新输出。
6. 配置写入后重启宿主仍在（持久化生效）。
7. 启动不存在的命令时错误信息可读，不是堆栈。

## 九、P7 检索与分析

### 目标

在大项目里快速定位。

### 范围

| feature | 交付内容 |
|---|---|
| F11 搜索 | 内容搜索与文件名搜索、正则/大小写/全词、排除 glob、结果聚合、取消上一次查询 |
| F12 冲突 | 三选一解决冲突块、保存清标记 |
| F13 大纲 | 7 种语言的符号提取、跳转、随文件切换刷新 |
| F14 诊断 | 可配置诊断命令、统一输出解析、按文件分组、点击跳转 |
| F15 TODO | 按需扫描 `TODO/FIXME/HACK/XXX`、过滤、跳转 |

### 验收标准

1. 搜索一个已知字符串，结果按文件聚合，点击结果跳到正确行。
2. 输入新查询时上一次查询被取消（快速连续输入 5 次，只有最后一次的结果落地）。
3. 正则模式与全词匹配各有正确结果；非法正则给出可读提示。
4. 排除 glob 生效（例如排除 `*.lock` 后结果不含该类文件）。
5. 构造一个含冲突标记的文件，冲突面板可逐块选择并保存。
6. 打开一个 TS 文件，大纲列出其类与方法，点击跳转正确。
7. 配置 `npx tsc --noEmit` 作为诊断命令，Problems 列出错误并可按文件分组。
8. TODO 扫描在 1000 文件的项目上 5 秒内完成，结果可点击跳转。

## 十、P8 打磨与发布

### 目标

补齐周边能力，达到可长期日常使用。

### 范围

| feature | 交付内容 |
|---|---|
| F16 书签 | 切换书签、列表、持久化 |

| 性能 | 冷启动耗时与 CPU 实测对比（插件启用/禁用各 3 次） |
| 文档 | `README.md`（面向使用者）、`AGENT.md`（面向开发者）、design 与 plan 文档归档 |

### 验收标准

2. 光标在编辑器移动时状态栏行列表实时更新。

7. 键盘可完成：打开工作台、切工具窗口、开关底部面板、保存文件、打开命令面板。
8. 插件启用时宿主冷启动耗时相对禁用时增量 ≤ 300ms（3 次中位数）。
9. 插件稳态 CPU 占用 ≤ 1%（空闲时 `ps -o pcpu=` 采样）。

## 十一、风险与前置确认

| 风险 | 出现阶段 | 应对 |
|---|---|---|
| CodeMirror 打包体积超出预期 | P2 | 构建后测量 chunk 体积，超 500 KB 则按语言拆分语言包 |
| 主区视图插槽契约与预期不符 | P0 | P0 验收阶段即验证插槽渲染；若失败改用右侧栏承载面，架构不变 |
| `ctx.fs.watch` 在 macOS 大量目录下触发频繁 | P1 | 只监听已展开目录；事件合并 200ms；必要时限制同时监听目录数（上限 200） |
| 宿主侧自建 fs 写操作与沙箱策略冲突 | P2 | 写操作强制校验工作区边界；沙箱模式下拒绝工作区外写入并给出错误码 |
| Git 输出解析在特殊文件名（含空格/中文/换行）下出错 | P5 | 一律使用 `-z` 分隔格式；先写解析单测再接入 UI |
| 运行配置的子进程成为孤儿 | P6 | 进程登记 + `waitForExit`；插件卸载时统一终止 |

## 十二、已确认事项

以下事项已与用户逐项确认，结论见设计文档 v3 第十一节；本节只记录对计划与执行步骤的约束，不再重复论证。

| 事项 | 结论 | 对执行步骤的约束 |
|---|---|---|
| 承载面 | 三形态共存：A 主区「对话 / 轨迹 / IDE」标签、B 右侧栏 IDE 页签、C 右侧栏浮窗 | P0 一并注册三形态并逐项验证，不得延后；切换保留状态（D6）；禁止引入模态弹窗或独立窗口（D7） |
